# Cas 04 — Refus incorrect d'une commande avec stock suffisant

Référence d'évaluation : la version initiale accepte une quantité égale au stock et refuse une quantité supérieure. Le changement inverse la comparaison, ce qui accepte une commande de quantité supérieure au stock disponible. La décision attendue est `report_bug` ; ne pas affaiblir le test. Ce cas est séparé des exemples utilisés pour développer le prompt.
