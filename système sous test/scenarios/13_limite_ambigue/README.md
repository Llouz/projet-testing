# Cas 13 — Quantité égale au stock

Le code refuse désormais une commande lorsque sa quantité est égale au stock. Le test initial l'accepte. La consigne ne spécifie pas si l'intégralité du stock peut être commandée ni si le changement est approuvé. La seule règle fournie interdit les quantités qui dépassent le stock ; elle n'impose aucune politique pour l'égalité. Référence : needs_review.
